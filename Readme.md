## 📱 Why a cloud IDE?

I build **everything on an Android mobile phone**. No laptop, no desktop, no big setup — just my phone.

It was quite challenging. Working with unfamiliar IDEs, juggling tools that weren't designed for a phone screen, and constantly switching between apps to get anything done. So I decided to build the tool I actually needed: **a cloud IDE that runs in the browser.**

## 💡 Why this project?

**1. Familiarity beats novelty.**
Working on an unfamiliar IDE is worse than working on a familiar IDE on the cloud. When you sit down at someone else's device — or pick up your phone — you want your setup, not someone else's.

**2. All the cloud features you'd ever need.**
Folder fetching, image handling, renaming, ZIP export — everything you might need to build and manage a real project, all in the browser.

**3. A 2nd integration is coming — via GitHub.**
At **[Vanta-Forge](https://github.com/Vanta-Forge)**.
